Working brief — not landing-page copy

Portomatic

Users

  • Coding agents
  • iOS developers using coding agents
  • Vibe-coding platforms building mobile apps

Product

  • A remotely hosted iOS simulator
  • Runs an iOS app without renting a Mac mini
  • Embeds in any webpage or webview through an iframe
  • Built to be ergonomic for a coding agent

How it solves the problem

  • Give each coding agent an isolated simulator to iterate against and test its implementation
  • Scale simulator sessions quickly instead of managing a fleet of Mac minis
  • Treat simulator infrastructure more like cattle
  • Primary action: remote host a real app
  • Secondary action: ask ChatGPT about Portomatic

Questions potential users may have

QuestionAI suggested answerHuman answer
What do I provide: a zipped Simulator .app, an .ipa, or source code?
Upload a zipped iOS Simulator .app bundle. Portomatic does not need your source code, and an App Store .ipa is built for a physical device rather than the Simulator.
Who builds the app if compiling it still requires a Mac?
You or your existing CI system build the Simulator app. Portomatic starts and hosts the resulting build; it does not compile the source code. [Confirm whether a hosted build step is planned.]
Is this Apple Simulator or an emulator? What is not compatible?
Portomatic runs apps built for the iOS Simulator in a lightweight remote runtime. It is not a physical iPhone, so hardware-only behavior and device-only binaries may not work. [Define the exact compatibility boundary.]
Do camera, Bluetooth, notifications, location, and other device features work?
The core app UI, touch input, networking, and location testing should work. Camera, Bluetooth, push notifications, and other hardware-dependent features need an explicit support list. [Confirm supported device features.]
Can multiple agents run isolated simulators without stepping on each other?
Yes. Each agent gets an isolated simulator session that can be started, reset, and destroyed independently, so concurrent agents do not share app state.
Can an agent see, control, inspect, and reset the app through the API or iframe?
Yes. An agent can view and control the app through the embedded session and use the API to interact with and reset it. [Confirm available inspection data, such as logs, screenshots, and accessibility state.]
